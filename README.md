### ENCRYPT CMP
**Blockchain-Anchored Consent Management Platform for India's DPDP Act**

> 🥇 **Winner — Women in Technology Award, CSIC 1.0** (Cyber Security Innovation Challenge)
> Selected from **30,000+ innovators** and **970+ teams** down to **20 finalists**.

I led the team that designed and built this from the ground up — not a hackathon toy, but a system built to survive a real audit. It translates the DPDP Act (2023) into working infrastructure: every consent receipt is hashed and anchored on Ethereum (Sepolia), so a record can't be quietly edited after the fact — only proven, one way or the other.

| | |
|---|---|
| ⚡ **Zero-dependency SDK** | 795 lines, no npm, no build step, one `<script>` tag |
| 🌐 **Multilingual by design** | English, Hindi, Tamil, Telugu, Kannada, Malayalam |
| 🔗 **On-chain verification** | Solidity contract (`ConsentVault.sol`) anchors hashes on Sepolia — no personal data ever touches the chain |
| 📊 **Built-in benchmarking** | P50/P95/P99 latency tracking across save, revoke, hashing, and RPC calls |
| 🧩 **Battle-tested** | Deployed across a fintech lending platform and a government FIR-filing portal |
